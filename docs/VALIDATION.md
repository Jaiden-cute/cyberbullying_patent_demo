# 原型验收记录

## 学校心理咨询中心演示

通过界面测试和本机浏览器，使用独立数据库依次提交五个虚构场景。第 1 次展示被排除的作业消息和实际选出的重点回应，第 3 次在首页显示对比的两个历史日期，第 4 次展示「较高风险」及保存证据、屏蔽或举报等跟进动作，最后一场触发安全优先和人工复核提示。通过「历史与跟进」保存跟进情况，刷新后从 SQLite 读回。全量 pytest 为 72 项通过。

此前在独立数据库实跑前三个场景，三次均为 MODEL。第三次从 SQLite 读取前两条历史并完成两次比较，历史掩饰程度均低于重复模式门槛，因此 P=0。[五场景持久化与分析记录](../reports/user_demo_validation.json) · [首页连续三次模型分析](../reports/user_demo_ai_history.json) · [演示程序修改说明](DEMO_UPDATE.md)

## 前期验收

验收在 Windows 64 位 Python 3.12 环境执行。浏览器手动验证了示例加载、S1–S7 运行、S3 真实八类概率显示和 S7 写入状态。界面测试另覆盖人工修正类别与参与者、历史回看和跟进写入。SQLite 示例库检查为 `ok`，保存了 10 条原始消息、3 个事件、5 条候选回应和 40 条特征记录。
