# 学校心理咨询中心演示录屏说明

录制约 5–6 分钟。使用内置虚构场景、同一个录屏数据库和默认的「规则演示」。以咨询中心工作人员的视角，说明发生了什么、为什么值得关注、接下来怎么跟进。

## 启动

在仓库根目录打开 PowerShell。现有环境可以直接执行以下两行。新环境的安装见 [README](../README.md)。

```powershell
$env:PATENT_HISTORY_DB = "state/recording-$(Get-Date -Format 'yyyyMMdd-HHmmss').sqlite3"
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1
```

打开终端显示的 URL。在左侧「消息来源」选择「虚构演示案例」，保持「受影响学生」为「同学丙」。按表中顺序选择场景，每次点击「研判本次事件」。如果需展示导入，选择「导入 JSON / CSV」并上传表中同名文件。

| 时间 | 操作 | 画面中要看的内容 |
| --- | --- | --- |
| 00:00–00:30 | 进入「事件研判」，介绍使用者和虚构案例。 | 左侧用于选材料和受影响学生，中间用来查看研判结果。 |
| 00:30–01:30 | 运行第 1 次（`data/synthetic_scene_A_B01.json`）。 | 先看群聊事件摘要。画面显示两条相关回应、被排除的数学作业消息，以及结合事发情境需要进一步了解的回应。 |
| 01:30–02:15 | 运行第 2 次（`data/synthetic_scene_B02.json`）。 | 学生在群里接着刚才的话回应，系统将这句回应关联到本次事件。查看「一般关注」和具体跟进动作。 |
| 02:15–03:10 | 运行第 3 次（`data/synthetic_scene_B03.json`）。 | 在「为什么值得关注」查看系统从已保存记录比较了前两次回应，把出现过的相似表达纳入研判。 |
| 03:10–04:00 | 运行第 4 次（`data/synthetic_scene_elevated.json`）。 | 结合前三次历史得出「较高风险」，工作人员协助保存证据、屏蔽或举报，并确认可请谁协助。支持策略和参考话术可按需展开。 |
| 04:00–04:45 | 运行「安全优先 · 严重威胁」（`data/synthetic_scene_C.json`）。 | 展示安全信号、高风险提示，以及优先确认学生安全和安排人工复核。 |
| 04:45–05:45 | 进入「历史与跟进」，选择第三次事件，填写「已与学生核对群聊记录，约好明天再次沟通。」点击「保存跟进记录」。刷新后再打开该事件。 | 回看当时的事件、建议以及工作人员填写的处理情况。 |

如需另外录制模型辅助分析，换用一个新的录屏数据库，再按顺序运行前三个场景。每次打开「分析设置」，选择「模型辅助分析」并勾选「使用 AI 生成回复」。分析使用标记为 `synthetic_training_demo` 的分类器，本机 Qwen 服务可用且生成内容通过校验时，回复显示「AI 生成」。本机实测每次约 42–66 秒。
