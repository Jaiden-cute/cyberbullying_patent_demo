# 用户端录屏操作说明

录制约 5 分钟。使用内置虚构场景、同一个录屏数据库和默认的「规则演示」。演示内容为聊天输入、分析、支持建议和历史回看。

## 启动

在仓库根目录打开 PowerShell。现有环境可以直接执行以下两行。新环境的安装见 [README](../README.md)。

```powershell
$env:PATENT_HISTORY_DB = "state/recording-$(Get-Date -Format 'yyyyMMdd-HHmmss').sqlite3"
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1
```

打开终端显示的 URL。使用同一数据库依次提交下面四个场景。首次录制可以在「消息来源」选择「虚构测试数据」。如果需要展示导入，选择「导入 JSON / CSV」并上传表中同名文件。

| 时间 | 操作 | 画面中要看的内容 |
| --- | --- | --- |
| 00:00–00:30 | 启动服务，进入「用户交互」。 | 页面标题、消息来源、当前受影响对象和「开始智能分析」。说明使用虚构数据。 |
| 00:30–01:35 | 选 A / B 第 1 次，或导入 `data/synthetic_scene_A_B01.json`。选择「同学丙」，点击分析。 | 输入中有嘲讽、两条后续回应和一条数学作业消息。查看「给你的回应」和「下一步怎么做」。默认回复标为「预设支持回复」。 |
| 01:35–02:35 | 选 B 第 2 次，或导入 `data/synthetic_scene_B02.json`。保持同一对象，点击分析。 | 查看第二次分析给出的支持回复，进入历史可看到两次提交。 |
| 02:35–03:35 | 选 B 第 3 次，或导入 `data/synthetic_scene_B03.json`。完成分析后进入「历史记录」，筛选「同学丙」。 | 可以逐条回看三次分析给出的支持回复。 |
| 03:35–04:25 | 回到「用户交互」，选 C，或导入 `data/synthetic_scene_C.json`，点击分析。 | 屏幕显示需要人工复核、向可信任的成年人求助，以及外部通知未发送。该虚构场景只有威胁消息，仍能触发安全提示。 |
| 04:25–05:00 | 刷新页面，在「历史记录」筛选同一个对象并回看最新记录。 | 四次提交仍可查询。结尾说明演示采用虚构聊天及文字分析。 |

如需另外录制模型回复，打开「分析设置」，选择「模型辅助分析」并勾选「使用 AI 生成回复」。只有本机 Qwen 服务可用、并且生成内容通过校验时，回复来源才显示「AI 生成」。CPU 服务的运行耗时可能需要单独留出时间。

## 幕后验收

演示页面只呈现用户操作和支持结果。数值和每步证据保存在后台，以下结果从空数据库逐次运行取得：[A / B / C 完整计算与重新读取的 SQLite 记录](../reports/user_demo_validation.json)。

| 场景 | 后台结果 |
| --- | --- |
| A / B1 | 数学作业消息被排除，两个相关回应均通过阈值，代表回应为 `a-reply-1`。 |
| B2 | 无显式回复 ID 的回应由其余关联特征通过判断。 |
| B3 | 读取两条此前独立保存的记录。两次比较均使用八维文本向量，P≈0.381060，F≈0.486583。 |
| C | U 未计算，独立安全规则仍触发人工复核。 |
